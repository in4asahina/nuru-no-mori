01 / POSITION　三つの位置

三つの鏡が向き合うと、
さらに、わたしは無数に広がっていく。

万博いのちの未来、null²ⁿ、攻殻機動隊。三枚の鏡で三角形に囲むと、わたしの像は一列ではなく、床いっぱいに広がっていきます。どの像も、通ってきた鏡の色を少しずつ帯びています。

いのちの未来null²ⁿ攻殻機動隊
ドラッグで回す ・ ピンチ／ホイールで寄る

この端末では立体の鏡を表示できませんでした。三枚の鏡（万博いのちの未来、null²ⁿ、攻殻機動隊）で三角形に囲んだ中心に「わたし」がいて、鏡どうしが映し合うことで、わたしの像が無数に広がる図です。

いのちの未来石黒浩氏のパビリオン。アンドロイドという、重さのある身体を持つ分身と暮らす50年後を、祖母と孫娘の物語で体験しました。私たちはすでに「物質の分身」を見ています。

null²ⁿ落合陽一氏の常設シアター。テーマは「鏡の再発明」。知識・声・容姿からデータの分身がつくれる時代に、鏡はどう生まれ変わるのか。今度は自分が、その鏡の前に立ちます。

攻殻機動隊機械の身体（義体）に、その人らしさ（ゴースト）が宿る世界。30年前に描かれた、物質と情報のあいだで揺れる身体の物語です。三枚目の鏡として立てると、二つの分身を映し合うだけだった鏡が、わたしを無数に広げはじめます。

02 / SIX ROOMS　三枚目の鏡のことばを持って歩く

六つの部屋を、
映画『GHOST IN THE SHELL / 攻殻機動隊』(1995年)のことばと巡る。

ROOM 01 / GATE　門　皆空鏡門 ・ 震える

自分が自分であるためには、
驚くほど多くのものが必要なの。

草薙素子

夜の海から上がった素子が、船の上でバトーに語ります。他人と自分を分ける顔、意識せずに出る声、子どものころの記憶、未来の予感。自分を形づくる部品を、一つずつ数えていく場面です。

攻殻機動隊の素子は、自分を自分にしている部品の多さを数えました。万博いのちの未来の最初のゾーンでは、人が土偶や仏像、人形といったモノの形に「いのち」を宿してきた歴史を見ました。どちらも、自分やいのちを「何でできているか」から考えています。

ところがnull²ⁿの門は、その部品の一つである名前や肩書きを、最初に置いていく部屋です。足していくのではなく、手放すところから始まる。素子が数えた部品のうち、どれを手放しても自分でいられるのか。門をくぐる瞬間の「震える」は、その問いの手ざわりなのだと思います。

名前を置いていったあと、私に残っているのは何だろう。

ROOM 02 / FIRST ROOM　壱の間　さよならホモ・サピエンス ・ 戸惑う

もしかしたら、自分はとっくの昔に死んじゃってて、
今の自分は電脳と義体で構成された
模擬人格なんじゃないか、
いや、そもそも、あたしなんか
存在しなかったんじゃないかって

草薙素子

9課のラボに届いた謎の義体について、草薙素子とバトーが調査に出発する場面。その義体は、脳を持たないのに、ゴーストのようなものを宿しているらしい。素子はその義体に自分を重ね、自分自身の存在を疑いはじめます。本当の自分はもう失われていて、機械の身体と電子の脳が、自分らしさをまねているだけではないか。さらには、はじめから自分などいなかったのではないか、とまで口にします。

素子が疑ったのは、自分がすでに「写し」の側にいるのではないか、ということでした。電脳と義体があれば、顔も声も記憶も、自分らしさはまねできてしまう。null²ⁿのMirrored Bodyも、容姿・声・知識を登録すると、自分そっくりに話し、動く分身をつくります。30年前の攻殻機動隊が投げかけた疑いを、いまはアプリで誰もが試せるようになっています。

万博いのちの未来のゾーン2では、余命の近い祖母が、自分をアンドロイドという物質の身体に移すかどうかで迷いました。移ったあとの自分は、本当に自分なのか。素子は同じ問いを、自分がもう移された側かもしれない、という場所から見ています。「さよならホモ・サピエンス」と名づけられた壱の間で、私たちはどんな自分に出会うのでしょう。もしデータの身体に写された自分に出会ったら、今度は私たちが本物の側に立って、その分身に同じ疑いを向けることになります。けれど分身から見れば、疑われているのはこちらかもしれない。「戸惑う」という部屋の気持ちは、その向きの入れかわりから来るのかもしれません。

自分の分身に、足りないものは何で、多すぎるものは何だろう。

ROOM 03 / SECOND ROOM　弐の間　無眼界の夢 ・ 整う

今われらは鏡をもて見るごとく
見るところ朧なり。

コリント前書 13章12節（文語訳聖書）

光の届かない夜の海に、素子が一人で潜っていく場面。浮かび上がる途中、どこからともなく聞こえてくる声が、この一節を語ります。のちに人形使いだとわかる声です。

鏡で見ても、見えるものはぼんやりしている。攻殻機動隊のこの一節は、目にたよる限り、自分の本当の姿ははっきりしない、と言っているようにも読めます。

万博いのちの未来の最後のゾーン「まほろば」は、音と光に満ちた部屋でした。私たちはそこで、身体の制約から解き放たれた人の姿を「見て」きました。null²ⁿの弐の間の名前は、その逆を向いています。「無眼界」は般若心経で「見るという働きもない」ことを言う言葉です。光の中で解放を見た私たちが、今度は「見ない」ことを名前に持つ部屋に入る。鏡の前でぼんやりしていたものが、見ることを手放したときに「整う」のかもしれません。

見ることを手放したとき、自分の身体はどこまでだと感じるだろう。

ROOM 04 / THIRD ROOM　参の間　質量への憧憬 ・ 驚く

疑似体験も夢も、存在する情報は
すべて現実であり、そして幻なんだ。

バトー

記憶を書き換えられていた清掃局の男が、妻と娘の記憶も、大切にしていた家族の写真も、作られたものだったと知らされます。その取り調べのあとに、バトーが口にすることばです。

攻殻機動隊の清掃局の男にとって、家族の写真は記憶をつなぎとめる「重さのある証拠」のはずでした。それが作り物だったと知る場面は、写真や映像を記録として残してきた私には、とても痛い場面です。

一方、万博いのちの未来のゾーン1で見た人形や仏像は、人が記憶や祈りを重さのあるモノに託してきた証しでした。null²ⁿの参の間の名前は「質量への憧憬」。情報ならいくらでも書き換えられる時代だからこそ、手ざわりのあるモノに惹かれる。それが「質量への憧憬」なのだと思います。けれど、その手ざわりさえ現実なのか幻なのか、わからなくなる瞬間があるのかもしれません。

懐かしいものに出会ったときに湧く記憶は、本当に私のものだろうか。

ROOM 05 / FOURTH ROOM　肆の間　潜在空間の夢 ・ トぶ

私はAIではない。
私のコードはプロジェクト2501。
私は情報の海で発生した生命体だ。

人形使い

捕らえられた人形使いが、自分は生命体だと名乗り、亡命を求める場面です。人間のDNAもまた、自分を残すためのプログラムにすぎないのではないか、と問い返します。

攻殻機動隊の人形使いは、情報の側から生まれた生命でした。万博いのちの未来の「まほろば」が描いたのは、身体の制約から解き放たれ、自由に身体を選んで生きる1000年後の人間でした。向きは逆ですが、どちらも生命と情報の境目をなくしています。

null²ⁿの肆の間は「潜在空間の夢」。AIが世界をとらえる見えない空間を、名前に持つ部屋です。境目がなくなったあとの世界を、その内側から見せてくれる部屋なのかもしれません。「トぶ」という気持ちは、身体の輪郭から一度外へ出ることだと読みました。

AIの目に映る世界の中で、私はどんな形をしているだろう。

ROOM 06 / BRIDGE　橋　記号の彼岸 ・ また来る

然れど、かの時には
顔を対せて相見ん。

コリント前書 13章12節（文語訳聖書）

人形使いと一つになる直前、弐の間で聞いた一節の続きが語られます。ラストでは、子どもの身体に入った素子が、ネットは広い、どこへ行こうか、と言い残して出ていきます（要旨）。

鏡越しにぼんやり見ていたものと、最後には向かい合う。null²ⁿの最後の部屋「記号の彼岸」で、私たちは通ってきた六つの部屋を振り返ることになるでしょう。そのとき私たちは、万博いのちの未来で見た物質の分身と、null²ⁿで出会った「鏡の再発明」を、ようやく並べて見られるのだと思います。

そして攻殻機動隊の素子が新しい身体で出ていったように、null²はnull²ⁿに、万博いのちの未来は「いのちの未来＋」に、それぞれ姿を変えて万博のあとも続いています。「また来る」は、終わりではなく出発のことばです。

最後に振り返ったとき、いちばん印象に残っている部屋はどこだろう。
